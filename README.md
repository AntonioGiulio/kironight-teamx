# kironight-teamx

Progetto del Team X per la KiroNight.

## Struttura

- `.kiro/steering/`: contesto di prodotto, stack e struttura che Kiro usa in ogni sessione
- `.kiro/specs/`: spec per feature (requirements → design → tasks)
- `.kiro/skills/`: procedure riutilizzabili (una cartella per skill con `SKILL.md`)
- `.kiro/hooks/`: hook dell'agente
- `.kiro/settings/mcp.json`: server MCP del progetto
